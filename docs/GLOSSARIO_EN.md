# English terminology — what gets translated and what does not

The ROM is English. This file records the line between the two, because the
distinction is not "Portuguese word, translate it": half the point of the game
is that it is set somewhere with Portuguese names.

## The rule

**Names stay. Everything else goes to English.**

A name is what you would not translate on a map, in a passport or in a field
guide: a place, a person, a creature, a vessel. *Boitatá* stays Boitatá in
every language, the same way Pikachu is Pikachu and Rio de Janeiro is not
"January River".

Everything that is not a name is prose, and prose is English — including the
words that look like names because the game writes them in capitals. A faction,
a concept, a job title, a badge, a facility and an honorific are all common
nouns wearing capital letters, and leaving them in Portuguese is what makes an
otherwise English line read as half-translated.

## Translated

### Concepts and factions

| Portuguese | English |
|---|---|
| DESENCANTO | DISENCHANTMENT |
| VINCULO / VINCULOS | BOND / BONDS |
| ARQUIVO VIVO | LIVING ARCHIVE |
| CONSORCIO HORIZONTE | HORIZON CONSORTIUM |
| HORIZONTE *(the organisation)* | HORIZON |
| LEMBRANTE / LEMBRANTES | REMEMBRANCER / REMEMBRANCERS |

`Lembrante` is a coinage from *lembrar*, to remember: the faction that keeps
what HORIZON wants forgotten. **Remembrancer** is a real English word for an
official keeper of records, and it is a coinage in the same direction, so it
carries both halves — the archivist and the one who refuses to let go.

`Desencanto` is not merely forgetting. In Brazilian folklore the creatures of
this game are *encantados*, enchanted beings; *desencanto* is the undoing of
that enchantment. **Disenchantment** is the only English word that keeps the
folklore and the memory loss in one term.

### Titles, roles and honorifics

| Portuguese | English |
|---|---|
| SEU *(before a name)* | MR. |
| DONA *(before a name)* | MRS. |
| MAE *(the speaker label)* | MOM |
| LIDER | LEADER |
| CAMPEA / CAMPEAO | CHAMPION |
| AGENTE | AGENT |
| ATIVISTA | ACTIVIST |

`Seu` and `Dona` are not parts of the names they precede — they are the
Brazilian spoken forms of *senhor* and *senhora*. An English reader parses
"SEU BENTO" as a first name, which is exactly the wrong reading: he is
Mr. Bento, the old sailor, and vanilla's equivalent is MR. BRINEY.

## Where the line was hard

**HORIZONTE.** A company name, and company names usually survive translation.
It is translated here anyway for two reasons: the project's own English text
already settled on HORIZON before this pass, and the word is doing work in the
prose — a consortium named *Horizon* is selling a future, which is the whole
joke. Keeping it Portuguese in an English sentence buys nothing and costs the
pun.

**Place names with common nouns inside them.** PORTO DAS REDES contains
*porto* and *redes*, both ordinary words, and it would be easy to slide into
"NETS HARBOR". It stays whole. A place name is one name, not a sentence, and
translating half of the map is how a setting stops being anywhere.
