# Arauna battle-data checkpoint

This checkpoint replaces inherited level-up moves with deterministic, type-aware learnsets for all 386 Fakemon.

## Runtime rules

- Every Fakemon has a dedicated `sAraunaNNNLevelUpLearnset`.
- A basic attack and an identity/status move are available from level 1.
- The first same-type attack is available by level 5.
- Dual-type species begin receiving their secondary type from level 17.
- Power grows through level 52, with physical or special moves selected from the species' higher attacking stat.
- Field-progression moves (`Cut`, `Fly`, `Surf`, `Strength`, `Rock Smash`, `Waterfall`, and `Dive`) are intentionally excluded from level-up learnsets.

The data is generated by:

```sh
python3 tools/arauna/build_arauna_learnsets.py
```

The packed-Dex validator checks all 386 declarations, species-table references, minimum move counts, and field-move exclusions.

## Temporary battle shells

Abilities, teachable/TM compatibility, egg moves, and cries still come from the Emerald/expansion slot used as the technical shell. They remain playable placeholders and will be redesigned after the world encounter curve is stable.

No ROM build is required for this content checkpoint.
