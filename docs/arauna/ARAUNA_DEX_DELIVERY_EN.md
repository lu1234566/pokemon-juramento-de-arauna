# Complete Arauna Dex — English-first delivery

This delivery indexes all 386 Fakemon used by the first English build of **Pokémon Juramento de Arauna**.

## Files

- [Complete English Dex catalogue](ARAUNA_DEX_COMPLETE_EN.csv): names, types, English category, habitat, Dex text, stats, abilities, evolution, inspiration, art provenance and every editable asset path.
- [Editable art archive](../../graphics/arauna/arauna_editable_fakemon_assets.zip): 386 numbered folders containing `anim_front.png`, `back.png`, `icon.png`, `normal.pal`, `shiny.pal` and `candidate_profile.json`.
- [Art production manifest](FULL_DEX_ART_MANIFEST.csv): technical dimensions, palette counts, animation and production method.
- [Engine mapping](ARAUNA_DEX_ENGINE_MAPPING.csv): exact Arauna number to battle-engine slot mapping.

## Art provenance

- #001–#009: hand-prepared starter-family packages.
- #010–#314: front references supplied for the project, converted to the GBA format. Their back sprites are technical silhouette reconstructions and still need individual visual review.
- #315–#386: original procedural concept packages created from each entry's name, types, category and inspiration because no reference image was available.
- Integration is not equivalent to visual approval. Every package can be replaced in its numbered folder without changing Dex numbering, scripts or save identity.
